# Carrier Archive · The Modem Handshake

An illustrated, interactive history of landline modems from 300 bit/s to 56K. [Visit the exhibit](https://ahknight.github.io/modems-astra-xhigh/).

Open index.html in a modern browser or serve the repository root as static files. GitHub Pages serves the root of gh-pages with Jekyll disabled. There is no build step, analytics, external asset dependency or prerecorded audio download.

- index.html contains the introduction, origin story, epilogue and credits.
- chapters.js contains the eight sourced chapter narratives.
- signals.js builds the selected signal on demand. SIGNALS.md gives the technical evidence and limits.
- guide.js and player.js handle navigation, playback, oscilloscope drawing and timed transcripts.
- DEVLOG.md records implementation decisions and verification.
